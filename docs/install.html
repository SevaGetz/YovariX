Install

Install YovariX in three steps.

  1. 1

    Get a userscript manager

    Install Tampermonkey (recommended) or Violentmonkey.

  2. 2

    Install YovariX

    Click the button. Your manager opens a tab with the script details.

    Install
  3. 3

    Confirm and open X

    Press Install, then open x.com. YovariX settings are in the "More" menu.

Some plugins are not optimised for mobile yet. It will be fixed soon.
